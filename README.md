# 音乐 MV

按歌词和曲风生成编曲、分镜和对口型。个人项目，2026.07 至今。

## 做了什么

成片要跟着歌词走。先按输入的歌词和曲风生成编曲，并把干声和伴奏分开。后面的分镜和对口型都只使用这条干声。

自动抽出主歌、副歌、桥段的小节边界和词级时间戳，再按音乐段落排分镜时长和景别。主歌用来交代，副歌切到近景。

换镜头时歌手容易被画成另一个人。分镜关键帧会加载角色和风格 LoRA，把外貌和画风锁住，再用三维场景的相机参数约束机位和景别。

伴奏会把口型带偏。对口型阶段只用干声和词级时间戳重绘嘴部，其余人脸保持锁定。长音和拖腔做时序平滑，让口型停在同一个形状上。

后面的高清超分和插帧不再重绘脸，直接复用已经对齐的面部区域，避免闪烁和口型失步。副歌近景和角色关键帧设了人工确认，通过以后才继续生成。
