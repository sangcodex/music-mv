# 音乐 MV

从歌词和曲风出发，生成编曲、分镜和对口型。个人项目，2026.07 至今。

## 项目是什么

成片要跟着歌走，而不是先有画面再对嘴。输入歌词和曲风，产出编曲、分镜和对上的口型。

## 我做了什么

- 先生成编曲，并分离干声与伴奏。后面的分镜和对口型都只用这条干声，避免伴奏把节奏和口型带偏。
- 抽出主歌、副歌、桥段的小节边界和词级时间戳，按段落排分镜时长和景别。主歌用来交代，副歌切近景。
- 换镜头容易变脸。关键帧加载角色和风格 LoRA，锁住外貌和画风，并用三维相机参数约束机位和景别。
- 对口型只重绘嘴部，其余人脸锁定。长音和拖腔做时序平滑。超分和插帧复用已经对齐的脸，避免闪烁和口型失步。
- 副歌近景和角色关键帧设人工确认，通过以后才继续生成。
