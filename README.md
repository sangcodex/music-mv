# 音乐 MV

根据歌词和曲风生成编曲、分镜与对口型。个人项目，2026.07 至今。

## 项目介绍

成片跟随歌曲推进，而不是先生成画面再事后对嘴。输入歌词和曲风，产出编曲、分镜和对上的口型。

## 完成内容

- 生成编曲并分离干声与伴奏。后续分镜和对口型只使用干声，避免伴奏干扰节奏和口型。
- 抽出主歌、副歌、桥段的小节边界和词级时间戳，按段落编排分镜时长和景别。主歌用于交代，副歌切近景。
- 关键帧加载角色与风格 LoRA，锁定跨镜头外貌和画风，并用三维相机参数约束机位和景别。
- 对口型只重绘嘴部，其余人脸锁定。长音和拖腔做时序平滑。超分和插帧复用已对齐的面部。
- 副歌近景和角色关键帧设置人工确认，通过后才继续生成。
